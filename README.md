## Overview

This project gives creative teams, designers, and strategists a faster way to move from a live website to a meaningful design brief. Instead of manually assembling a long audit document from scratch, the tool captures the essentials and generates a clean AI kickoff prompt.

It helps define:

- target website and business context
- brand tone and positioning clues
- research depth and creative direction
- design deliverables and strategic priorities
- non-negotiable elements to preserve
- supporting context and attachments

The output is designed to be copied into AI assistants and used as a structured creative brief for website audits and strategic design work.

## Why it matters

Most website reviews start with fragmented notes, inconsistent context, and manual synthesis. This tool provides a cleaner starting point — turning raw inputs into a cohesive creative brief that is easier to discuss, iterate on, and execute.

## Features

### ✨ Smart prompt generation
Generate a structured brief tailored to the project, objective, and research depth.

### 🧠 Strategic inputs
Capture business context, creative direction, constraints, and design goals in one place.

### 📎 Attachment support
Upload supporting files such as brand decks, notes, content references, and design assets.

### 📤 Copy & export
Copy the final brief directly or export it as a Markdown file for sharing or documentation.

### ⚡ Lightweight execution
The whole app runs in the browser without a build step or server-side setup.

## How to Use

1. Open the live demo link above.
2. Enter the target website URL.
3. Add your business context and design goals.
4. Choose the research depth and creative direction.
5. Add supporting notes or attachments.
6. Click `Generate Prompt`.
7. Copy the output or download it as Markdown.

## Local Development

Since this is a static HTML project, there is no build pipeline required.

### Open directly

```bash
open website-design-brief-generator.html
```

### Serve locally

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000/website-design-brief-generator.html
```
